In this paper, we have shown that chaos-based cryptography can be suitable to image encryption.
Indeed, we have proposed a naive implementation which lead to great results in various analysis tests such as visual, intensity and correlation between adjacent pixels. 
However, as we shown earlier in the paper, multiple chaotic maps are needed to get safe encryption, this could lead to larger computational time. \\

The proposed algorithm could be a basis to more complex algorithms for image encryption, for example, to reduce compute time, the representaion of floating-point number as 32 bits (or double floating-point number as 64 bits) can be use to avoid the encryption byte per byte as it is done in this paper.
